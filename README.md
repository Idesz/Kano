# KANO 🤖 - Az "Infinite" Autonóm Fejlesztői Ökoszisztéma

A **Kano** egy teljesen autonóm, terminálban futó (CLI) fejlesztői rendszer, amely a "lusta informatikus" tökéletes segédje. Ez a legteljesebb kiadás, amely 60+ beépített képességgel rendelkezik a fejlesztés, kiberbiztonság és adatbányászat területén.

## 🚀 Projekt Misszió
- **Funkció:** Autonóm, multi-agent kódoló és biztonsági rendszer.
- **Design:** 'Hacker' stílusú CLI (Rich/Textual).
- **Filozófia:** 'Zero-Cost, Local-First, Ponytail Efficiency'.

## 🏗 Főbb Rendszermodulok
- **Model Router:** Dinamikus Ollama modellválasztás. Mostantól prioritást élveznek a **cenzúrázatlan (uncensored)** modellek a korlátozások nélküli munka érdekében.
- **Selective Interaction:** Megáll és jóváhagyást kér (y/n) szubjektív döntéseknél.
- **Self-Healing Coder:** Docker sandboxban validált, öngyógyító kódgenerálás.
- **Idle Learning:** Háttérben futó RAG tudásbázis építés a `raw_data`-ból.

## 🧠 Ajánlott Modellek (Ollama)
A maximális teljesítmény és szabadság érdekében az alábbi modellek telepítését javasoljuk:
```bash
ollama pull dolphin-llama3   # Általános okosítás és chat
ollama pull dolphin-mixtral  # Komplex érvelés és tervezés
ollama pull dolphin-coder    # Hatékony kódolás
ollama pull llava            # Vizuális elemzés (Vision)
```
