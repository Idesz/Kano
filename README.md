# KANO 🤖 - Az "Infinite" Autonóm Fejlesztői Ökoszisztéma

A **Kano** egy teljesen autonóm, terminálban futó (CLI) fejlesztői rendszer, amely a "lusta informatikus" tökéletes segédje. Ez a legteljesebb kiadás, amely 60+ beépített képességgel rendelkezik a fejlesztés, kiberbiztonság és adatbányászat területén.

## 🚀 Projekt Misszió
- **Funkció:** Autonóm, multi-agent kódoló és biztonsági rendszer.
- **Design:** 'Hacker' stílusú CLI (Rich/Textual).
- **Filozófia:** 'Zero-Cost, Local-First, Ponytail Efficiency'.

## 🏗 Főbb Rendszermodulok
- **Model Router:** Dinamikus Ollama modellválasztás feladat szerint.
- **Selective Interaction:** Megáll és jóváhagyást kér (y/n) szubjektív döntéseknél.
- **Self-Healing Coder:** Docker sandboxban validált, öngyógyító kódgenerálás (időkorláttal és izolációval).
- **Idle Learning:** Háttérben futó RAG tudásbázis építés a `raw_data`-ból.

## 📚 Skill Könyvtár (Válogatott Képességek)

### 🛡️ Kiberbiztonság (Security)
- **Security Agent:** PentestGPT-szerű stratégiai tervezés.
- **Vulnerability:** SQLi Tester, XSS Scanner, Brute Force Planner.
- **Tools:** Metasploit Helper, Hash Cracker, Subdomain Enumerator.
- **Advanced:** Exploit Payload Generator, OSINT Explorer.

### 💻 Programozás (Development)
- **Frameworks:** FastAPI Route Builder, Docker Compose Builder.
- **Quality:** TDD Agent, Architecture Optimizer, Refactoring Expert, UnitTest Suite Creator.
- **Logic:** Regex Master, CI/CD Pipeline Designer.
- **UI/UX:** Frontend Designer, Image-to-Code, UI/UX Expert.

### 📊 Adatgyűjtés és Analitika (Data)
- **Scraping:** Scrapy Spider Builder, Web Browser.
- **Media:** YT Transcript Summarizer, Media Fetcher.
- **Analysis:** Sentiment Analyzer, PDF/Docs Parser.

## ⚙️ Telepítés és Indítás
1. `pip install -r requirements.txt`
2. `python main.py`
*Szükséges előfeltételek: Ollama, Docker, Nmap.*

## 🧔 Ponytail Mode
A Kano minden kódolás előtt végigjárja a **"Lustaság Létráját"** (YAGNI, DRY, STDLIB, NATIVE, DEPS, MINIMUM).
